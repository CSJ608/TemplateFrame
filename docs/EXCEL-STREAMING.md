# 模板 Excel 显式流式导出

`ExcelTemplateFiller.FillStreaming(template, target, contract, ExcelStreamingData, cancellationToken)` 是独立 opt-in 入口，返回校验警告，不返回输出流。旧 `Fill`、引擎及强类型服务不自动切换。

`ExcelStreamingData.Values` 与旧标量数据形状相同；`Tables` 接收 `IEnumerable<IReadOnlyDictionary<string, object?>>`。每个有效表只枚举一次，可重复使用同一个行字典；必须为不同表提供独立可枚举的数据源。数据源按工作表及行的物理顺序消费，不承诺契约顺序。枚举过程中不应修改契约或数据源映射。

模板在输入限额内缓冲、校验并加载 DOM。标量先填充，数据行随后从未填充原型克隆、立即填值、写入 ZIP 并释放；不会构造完整输出 DOM 或压缩结果缓冲区。内存与模板大小、单行大小及样式/包元数据有关，不随生成行数线性增长；调用方自行物化输入或使用 MemoryStream 接收输出仍会增加内存。

## 支持边界

- 同一工作表的多个独立单行原型表、多个工作表、稀疏页脚及标量。列命名区域必须为同一行的不同单元格。空数据保留原型行并清空绑定列；缺失数据的表保持模板。
- 保留原型其他单元格、样式、共享字符串及普通公式字面内容，不重算公式、不重写公式引用。
- TF_ 定义名按旧 Fill 的起点规则移动，表列范围扩展；非 TF_ 定义名（含打印区域）保持原内容，不进行公式解析。
- 合并区域按旧 Fill 规则移动：起点在原型行下方才整体平移；原型行或跨界合并不复制、不扩展。绘图锚点按旧规则平移，图片填充保留部件与关系。
- 同一原型行的多表、标量/图片命名区域与原型行交叠明确拒绝，避免执行顺序依赖或回写已输出行。
- 展开工作表仅支持基本属性、视图、列宽、数据、合并、打印设置、页眉页脚和绘图。超链接、自动筛选、条件格式、数据验证、原生 Excel Table 等额外结构暂不支持，提前拒绝而不回退高内存路径。未展开的工作表及其他部件仍保留。
- 展开工作表的共享/数组/数据表公式、带范围的公式以及绘图中的图表/graphic-frame 暂不支持，预检拒绝；普通公式保持字面内容。行号须唯一且升序，单元格地址须匹配所在行。
- 工作表 dimension 缓存省略，由读取器根据实际单元格确定。ZIP 字节和 XML 声明/属性顺序不保证相同。

## 资源和失败

保持 `TemplateFillOptions` 默认预算：累计十万数据行、一百万表格单元格，以及原有克隆 XML 预算；容量实验必须显式提高。惰性输入无法预知最终行数，逐行计费，含原型额外单元格；Excel 物理行数边界也检查。

为避免生成越界元数据，每张展开工作表按原有行、TF_ 范围终点、合并终点及绘图行标记中的最大行号预留空间；这是保守边界，即使某个跨界合并按旧规则不移动也计入。数据单元格文本超过 32,767 字符拒绝；单行对象/转换本身的内存由数据源负责，不是进程级硬限额。

调用方始终拥有模板和目标流；支持不可 Seek 的目标。输出从当前目标位置写入，不清空、不倒回。成功由调用方关闭目标；异常、超限或取消时可能已经产生部分 ZIP，必须丢弃。枚举器在成功和失败时释放。取消在阶段及逐行/逐列边界检查，无法中断调用方阻塞的 MoveNext、转换或同步 IO。库不设置全局并发信号量，宿主控制排队与调度。

## 实施记录

第一批：新增接口、直接 ZIP 输出及增量预算。Release 全量构建零警告错误；Excel 三框架各 215 测试通过（含 8 个新增场景），覆盖旧 Fill 对照、逆序契约多表、空表、非 Seek、复用字典、部分输出、异常/取消释放和提前拒绝。后续继续补充复杂包回归及有保护容量实验。

第二批：补充包保留、结构拒绝、元数据边界、恶意数据及目标写入失败回归；全量三框架 1,997 测试通过，构建零警告错误。独立探针接入惰性模板模式，6 列 1,000 / 10,000 / 100,000 行逐格验证通过，原保护线不变。后续完成大样本、最终文档和复核。

最终收尾（2026-10-26）：补充工作簿枚举顺序、多工作表独立位移、缺失可选表不枚举和非 Seek 输入所有权测试。Release 全量构建零警告错误；三框架共 2,006 次测试通过（Core 399、Word 492、Excel 702、Simple 413），方案及独立 probe 格式检查通过。6 列百万行 .NET 10 两次、.NET 8 一次及小文件并发逐格验证通过；结果、默认预算拒绝和测量限制见 [专项证据](reviews/template-streaming-2026-10-25/README.md)。实现按批本地提交，未推送，无待用户决策事项。
