# 分会话执行指令

## 使用方式

用户每次将一个代码块复制到新会话。按 S1 → S2 → S3 → S4 → S5 顺序执行，每项先由原协调会话复审通过，再启动下一项。不同会话共享工作区时不要同时修改仓库。

问题定义、基线证据和验收标准见 [评审台账](2026-09-07-review.md)。每条命令都包含独立工作的必要约束。

## 返回协调会话的复审指令

```text

请实际检查当前差异、相关实现和测试，必要时复现，重点检查是否解决原问题、有无回归、是否越界；不要只依据实现者总结或测试全绿判断。
由你更新台账为“验收通过”或“需返工”，提供证据。如果需要返工，只给我本会话的返工指令；通过后给我下一会话指令。不要自行实现修复。
```
