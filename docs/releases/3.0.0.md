## 符号服务器收尾

初始发布日志仅记录四个 nupkg 上传；snupkg 虽已附在 GitHub Release，但独立符号服务器抽样仍返回 404。[PR #7](https://github.com/CSJ608/TemplateFrame/pull/7) 修复了显式 V3 符号推送并提供仅 main 可触发的恢复入口；合并提交为 `2c71002485302732eae5032744e74da5da773cc6`，PR CI [39746024081](https://github.com/CSJ608/TemplateFrame/actions/runs/39746024081) 与合并后 CI [39746379195](https://github.com/CSJ608/TemplateFrame/actions/runs/39746379195) 均通过。

2026-10-22，符号专用工作流 [39746867271](https://github.com/CSJ608/TemplateFrame/actions/runs/39746867271) 成功完成：下载并校验既有 Release 的四个原始 snupkg，通过同一 release.yml 的 OIDC 身份补传到 NuGet 符号端点。常规 test/release jobs 按事件条件跳过，没有重新构建、重推主包或移动 `v3.0.0`。

2026-10-23，独立验收全部 **12 个 Portable PDB**：DLL CodeView GUID 与 PDB GUID 对应、PE 内嵌 PdbChecksum 与标准化 PDB 校验和相符；按官方符号 key 和 `SymbolChecksum` 请求头从 NuGet 符号服务器下载，12 项均为 HTTP 200，完整文件 SHA256 与 GitHub snupkg 中的原始 PDB 完全一致，失败项为零。结果见 [symbols-3.0.0-verification.json](../reviews/security-2026-10-22/symbols-3.0.0-verification.json)，协议依据见 [symbol-protocol-reference.json](../reviews/security-2026-10-22/symbol-protocol-reference.json)。至此主包、Release 资产和 NuGet 符号均已验收。
